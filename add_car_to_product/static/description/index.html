Direct Telegram Client Integration

Direct Telegram Client Integration connects a real Telegram account (phone number) to Odoo. It lets your team handle Telegram conversations directly inside Odoo and keep everything tied to CRM and Discuss.

Key Features

  • Direct Telegram account connection (non-bot) using a Telegram client session.
  • Message delivery states: supports tracking delivered/read status.
  • Replies support: send messages with proper reply-to (threaded replies).
  • Keeps Telegram conversations centralized in Odoo for faster response and better CRM context.
  • Automatic lead creation upon the first message
  • Communication history saved in CRM or Discuss
  • Display of name, photo, and channel tags for each contact

Module Functionality

  • Auto-create a lead for each new inquiry
  • Channel tags displayed in the lead card
  • Realtime notification about new lead/conversation for assigned Manager
  • Messaging, file sharing, manager reassignment
  • Message status updates (read/delivered)
  • Supports replies from Lead Chatter & Discuss Channel

Distribution

  • Last-agent handling or round-robin distribution
  • Manual reassignment of responsible user in the lead card

For implementation and support, contact the Netframe team

Configuration

1. To configure this Telegram Integration you need to authorize on my.telegram.org first

  • Create an App by entering App title & App short name (it could be anything You want)
  • After Your App is created copy Your App api_id & App api_hash
  • Right after You found this values, return to Odoo. Proceed to CRM > Configuration > Social media
  • Here create new Social Media record
  • 1. Enter it's name
  • 2. As social media type select Telegram (by Telethon)
  • 3. Select Your Company
  • 4. Choose a place where to store incoming messages
  • 5. Choose Sales team (members of this team will be used for Distribution
  • 6. Insert Your Telegram API ID
  • 7. Insert Your Telegram API Hash
  • 8. Name Your session (it could be anything You want)
  • 9. Enter Your Phone number (which You used to get access to my.telegram.org)
  • 10. Press "Connect to Telegram" button
  • After You Pressed "Connect to Telegram" button You will receive a verification code from Telegram via Telegram App (on Your phone or Desktop)
  • 1. Enter this code in wizzard
  • 2. Press "Telegram login"
  • After this Direct Telegram Client Integration Could be successfully used
